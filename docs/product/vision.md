# プロダクトビジョン

## ひとことで
**TOEIC Part 7 の長文を「目で追いながら、狙った速さで聞く」ための無料アプリ。**
iPhone（PWA）と Windows（.exe）で、同じ教材・同じ音声・同じ操作で使える。

## 誰のためか（ペルソナ）
| | ペルソナ | 状況 | いちばん欲しいもの |
|---|---|---|---|
| P1 | **伸び悩む社会人学習者**（スコア 400〜600） | リスニングはそこそこ、リーディングが時間切れ。通勤中と自宅PCで勉強 | 速く読む感覚。本番より少し速い音声で読む練習 |
| P2 | **スキマ時間の学習者** | スマホだけ。片手で操作、ロック画面から再生 | オフラインでも1タップで続きが聞ける |
| P3 | **自分の教材を持つ学習者** | 問題集やAIで作った長文を持っている | 自分の文章を自然な英語音声で聞き読みしたい |

> 開発者本人は P1 にあたる。最初の判断基準は「自分が毎日使いたいか」。そのうえで、公開して他の人が使える品質を目指す。

## 解決する課題
- 一般的なTTSアプリは**速さがWPMで指定できず**、本番の読む速さ（目安150〜200WPM）を体で覚えにくい
- 音声と文字が**ずれる**、または意味のかたまり（チャンク）で区切られていない
- Part 7 形式の**問題と聞き読みが別々**のアプリに分かれている

## 価値の柱（優先順）
1. **ずれない聞き読み**：チャンク単位のハイライトが音声とぴったり合う
2. **速さをWPMで扱える**：今日の自分の速さが数字で分かり、少しずつ上げられる
3. **どこでも同じ体験**：iPhone と Windows、オフラインでも動く
4. **解いて終わりにしない**：Part 7 の4択 → 解説 → 聞き読みで復習、の流れが1つのアプリで完結

## やらないこと（Non-goals）
- Part 1〜6 の対策や、TOEIC全体の学習管理アプリ（範囲を広げすぎない）
- アカウント登録やサーバーでのデータ保存（**ADR-0001**：サーバーを持たない）
- 有料課金や広告（当面）
- 公式問題の転載。教材はすべてオリジナル

## 成功の指標
| 指標 | 測り方 | 当面の目標 |
|---|---|---|
| 継続 | 本人が週5日以上使う | 4週間続く |
| 上達 | アプリ内の平均WPM（読む速さ） | 1か月で +20 WPM |
| 正答率 | Part 7 テストの正答率 | 70%以上 |
| 公開の品質 | 初めての人がヘルプを見ずに1問を聞き読みできる | 3人に試してもらって全員できる |

※ サーバーを持たないため利用状況は自動で集めない。本人の記録と、試してもらった人への聞き取りで測る。

## 公開にあたっての前提・制約
- **商標**：TOEIC は ETS の登録商標。アプリ内と README に「ETS とは無関係の非公式アプリ」と明記する
- **ライセンス**：
  - アプリのコードにライセンスを付ける
  - 同梱物のライセンスを表記する（Kokoro-82M は Apache-2.0、フォントは OFL）
- **費用ゼロで運用**：GitHub Pages、GitHub Actions、GitHub Releases の範囲で運用する
  - Windows のコード署名は有料なので、当面は署名なし（SmartScreen の警告が出る）とし、その旨を案内する
- **プライバシー**：学習記録は端末内（localStorage）だけに保存する。外部送信はしない
