# ストーリーマップ（要件の全体像）

要件はユーザーストーリーで書く：**「〈誰〉として、〈何〉をしたい。なぜなら〈理由〉」**。
1 件ずつの詳細と受け入れ条件は GitHub Issues にあり、ここでは全体の並びとリリースの区切りだけを持つ。

## 利用者の流れ（横軸）と機能（縦軸）

| 見つける・始める | 教材を選ぶ | 聞き読みする | 解く | 振り返る |
|---|---|---|---|---|
| インストール方法が分かる | 問題の一覧から選ぶ ✅ | チャンクでハイライト ✅ | 4択テスト ✅ | 正答率・WPM の記録 ✅ |
| 初回の使い方の案内 | 自分の長文を追加 ✅ | 声と速さを選ぶ ✅ | 解説を読む ✅ | 記録のバックアップ ✅ |
| 非公式アプリだと分かる | 難易度や形式で絞り込む | WPM で速さを指定 ✅ | 時間を計って解く | WPM の推移グラフ |
| | | オフライン再生 ✅（手動 DL） | | 苦手な問題を復習 |
| | | 音読モード（自分で読む間） | | 語注・チャンクの単語帳 |
| | | 自分の長文を Kokoro で聞く | | |

✅ = 実装済み

## リリースの区切り

### R1「人に勧められる」（公開の最低ライン）
- ライセンスと非公式の表記
- 公開向けの README（iPhone と Windows のインストール手順、SmartScreen の案内）
- 初回の使い方の案内
- テストと CI（パーサーの一致、教材データの検証、読み方の変換）
- Windows 版で端末の声が出ない不具合の修正

### R2「毎日使いたくなる」
- WPM の推移グラフ
- 苦手な問題の復習
- 音読モード
- 音声の自動ダウンロード（オフライン）

### R3「自分の教材でも」
- 自分の長文を Kokoro の声で聞く（方法の検証から）
- 教材の追加手順を型にする（作成 → レビュー → 検証 → 生成）

## 優先順位の付け方
1. 壊れている・公開を妨げるもの（バグ、法的な表記）
2. 変更を安全にするもの（テスト、構成の整理）。後の開発の速さに効く
3. 価値の柱（vision.md）に直結する学習機能
4. あると嬉しいもの
