# ADR-0001: サーバーを持たず、静的ホスティングだけで提供する

- 状態: 採用
- 日付: 2026-11（後追いで記録）

## 背景
個人開発で運用費をかけたくない。iPhone 単体でも使いたい。公開後も保守の手間を増やしたくない。

## 決定
GitHub Pages（静的ファイル）で配信する。重い処理（音声合成）は GitHub Actions で事前に行う。
利用者のデータは端末内（localStorage / Cache API）にだけ保存する。

## 検討した選択肢
| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| **静的ホスティング＋Actions** | 費用ゼロ、落ちない、個人情報を持たない | 利用者ごとの動的な処理（自分の長文の音声化など）ができない |
| 自前サーバー（Python API） | 何でもできる | 費用、障害対応、セキュリティ |
| サーバーレス（Cloudflare Workers 等） | 安い | Kokoro を動かすには非力、無料枠の制約 |

## 結果
- ＋ 運用費ゼロ、プライバシーの説明がシンプル
- − 端末をまたいだ記録の同期ができない（手動のバックアップで代替）
- 見直す条件：利用者が自分の長文を Kokoro で聞きたいという要望が強くなったとき
