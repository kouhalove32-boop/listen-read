# ADR-0005: 画面の文字と、読み上げる文字を分ける

- 状態: 採用
- 日付: 2026-11-05

## 背景
「9:00 A.M.」が「nine zero zero A.M.」、電話番号が「five hundred fifty-five…」のように不自然に読まれていた。

## 決定
`gen_audio.py` の `spoken()` で、合成の直前に読み方の文字列へ変換する。画面には元の文字を表示する。
変換はチャンク単位で行い、**チャンクの数と順序を変えない**（ハイライトの対応を保つため）。
ハッシュは読み方の文字列から作る。

## 結果
- ＋ 自然な読み。変換の規則を足すたびに、影響した教材だけが再生成される
- − 変換規則が増えると、表示と音声の差が分かりにくくなる → 規則ごとに単体テストを書く
