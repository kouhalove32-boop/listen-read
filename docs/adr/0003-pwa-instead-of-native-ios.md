# ADR-0003: iPhone はネイティブアプリではなく PWA にする

- 状態: 採用
- 日付: 2026-11（後追いで記録）

## 背景
SwiftUI でのネイティブ化を検討したが、Mac がなく、Apple Developer Program（年額）も払いたくない。

## 決定
ホーム画面に追加する PWA として提供する。Media Session API でロック画面から操作でき、Service Worker と Cache API でオフラインでも使える。

## 結果
- ＋ 費用ゼロ。Windows 版と同じコードを使える
- − iOS の PWA の制約を受ける（バックグラウンド再生の安定性、保存容量の上限、プッシュ通知の制限など）
- 見直す条件：Mac を入手したとき、または PWA の制約が学習体験を明確に損なったとき
