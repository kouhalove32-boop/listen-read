# ADR-0002: 音声は Kokoro で事前生成し、タイミング JSON を添える

- 状態: 採用
- 日付: 2026-11（後追いで記録）

## 背景
- 端末の TTS（speechSynthesis）は声の種類が端末依存で、イギリス英語が少ない。WPM も正確に出せない
- iPhone の中で Kokoro を動かす案（WebGPU）は、生成が終わらず実用にならなかった

## 決定
GitHub Actions で Kokoro-82M を使い、10 声 × 全教材の mp3 を事前生成する。トークンの時刻からチャンク単位の開始・終了秒を計算して JSON に保存する。
再生は `<audio>` の playbackRate で速さを変える。WPM は `words / speech 秒` から逆算する。

## 結果
- ＋ ハイライトがずれない。WPM が正確。声の品質が端末によらず一定
- − 教材を増やすたびに生成待ち（数十分）。リポジトリが肥大化する（ADR 候補：保存先の移行）
- − 利用者が追加した長文には使えない（端末の声にフォールバックする）
